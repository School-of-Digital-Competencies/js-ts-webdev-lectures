# SDC JavaScript/TypeScript Web Development Course Roadmap

## Month 1: DOM API, HTML Forms, CSS Preprocessors

### Week 1: JavaScript DOM API (Basics)

- DOM, CSSOM tree
- element selection methods
- events.

### Week 2: HTML Forms

- Form elements (`<form>`, `<input>`, `<select>`)
- Validation using HTML5 attributes.

### Week 3: JavaScript DOM (Advanced) + Dynamic Forms

- Dynamic element creation
- Form manipulation via DOM

### Week 4: CSS Preprocessors (SASS/LESS)

- Syntax, variables, mixins

## Month 2: Architecture, Bundlers, TypeScript, and Validation

### Week 5: Frontend Architecture

- Component-based approach
- Single responsibility principle
- DRY, KISS, YAGNI

### Week 6: Module Bundlers (Vite)

- Configuration
- .env files, dev, prod envs

### Week 7: TypeScript Basics

- DOM API and TypeScript
- Forms and TypeScript

### Week 8: Validation Libraries (Zod, Yup)

- Form validation with TypeScript schemas
- Zod/Yup libraries

## Month 3: Routing and State Management

### Week 9: Frontend Router (Basics)

- SPA
- History API

### Week 10: Frontend Router (Advanced)

- Dynamic routes, protected routes, nested routes
- Frontend routing libraries

### Week 11: State Management (Redux/Zustand)

- localStorage, sessionStorage
- Flux architecture, actions, reducers

### Week 12: Router + State Integration

- Synchronizing URL and application state

## Month 4: Headless CMS

### Week 13: Headless CMS Strapi

- REST, GraphQL API
- Strapi Installation

### Week 14: Frontend + CMS integration

- Fetch API, axios, try/catch

### Week 15: Deployment

- SSR, SSG, SPA, Caching
- Netlify/Vercel deployment

### Week 16: Final project - Teams or Solo

## Example Final Project

An e-commerce store with order forms (validation via Zod), routing, and data from a Headless CMS.
